# Healthcare Appointment Management System

## Project Overview
A front-end web prototype that allows users to enter patient details and book healthcare appointments.

## Features
- Patient name validation
- Doctor selection
- Appointment date selection
- Book and display multiple appointments
- Save appointments using browser localStorage
- Keep saved appointments visible after refreshing the page
- Responsive layout for different screen sizes

## Technologies Used
- HTML
- CSS
- JavaScript
- Browser localStorage

## Live Demo
[View the Healthcare Appointment Website](https://madhurishelke12.github.io/healthcare-appointment-management/)

## Testing
Manual test cases are documented in `TEST_CASES.md`. Tested scenarios include form validation, doctor selection, appointment booking, multiple appointments, refresh persistence, and responsive layout.

## How to Run
1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. Enter appointment details and test the booking functionality.

## Current Limitations
- Appointments are saved only in the same browser on the same device.
- There is no backend server or database integration yet.
- User authentication and role-based access are not implemented.

## Future Enhancements
- Java backend integration
