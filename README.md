# Healthcare Appointment Management System

## Project Overview
This project is a front-end prototype for a healthcare appointment management system. It demonstrates a simple interface for entering patient details and booking appointments.

## Features
- Patient name input
- Doctor selection
- Appointment date selection
- Appointment booking through a web interface
- Display of booked appointments

## Technologies Used
- HTML
- CSS
- JavaScript

## Live Demo
[Open the Healthcare Appointment Management Website](https://madhurishelke12.github.io/healthcare-appointment-management/)

## How to Run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Enter the appointment details and test the booking functionality.
